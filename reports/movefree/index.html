直播是增量引擎

品类两极分化

💡 链路选择核心逻辑：交易链路选择不取决于客户当下的能力，而取决于商品本身的客单价和商家属性。MoveFree 作为头部品牌 + 高客单的代表，建议以 CID-淘天/京东 + 小店闭环链路（享受品牌倾斜政策） 双链路并行，对标头部品牌商家的标准模型。

🛒 小店直购链路 — 平台主推的闭环阵地

小店直购有两大通道：ADQ 智投直跳小店（推荐）、微信小店全域通 CPA 模式（无转化不扣费）。小店 CVR/ROI 优势明显，推荐增投。

ADQ 直跳小店

  • ✅ ADQ 智投高效创建广告
  • ✅ 小店全域数据助攻提升拿量
  • ✅ 送礼 + 自然流提升 ROI
  • ✅ 先用后付提升 CVR
  • ⚠️ 技术服务费 2-5%（不同类目）

全域通（CPA 模式）

  • ✅ 无转化不扣费，成本稳定
  • ✅ 极简投放，最快两步创建
  • ✅ 全域流量一键智投
  • ✅ 支持无视频素材投放
  • ⚠️ 创建直播广告需勾选「商品信息」否则走电商审核通道
📌 小店直购选品特征：小店直跳以"短平快决策"商品为主，得益于小店全店归因 & 先用后付功能，ROI 及 CVR 显著高于传统直购链路，但 ARPU 有所下降。适合 MoveFree 大贸品试水闭环。小店送礼广告是撬动 CTR/CVR 双提升的高效手段。

🔗 CID 链路 — 保健品直购拓量重要阵地

CID 链路双投渗透率 41%，保健食品行业 CID 链路支持京东/天猫/PDD 三平台。

CID平台适用客群链路特点
京东 CID品牌客户 同时支持直跳京东小程序（链路最短效率更高）和二跳唤端（商详页表达尺度更广）
天猫 CID品牌客户 微信内流量支持二跳唤端，非微信流量支持应用直达
PDD CID (PA)白牌直购客户 腾讯PA自归因方案：归因准确率高，eCPM 竞争力提升 62.95%，消耗提升 30.15%（vs第三方归因）

📌 参考案例：汤臣倍健 × 京东CID — 头部保健品牌多品类矩阵增长标杆

前三力（商品力/内容力/经营力）为底层能力基石，「投放力」作为表达层（L2主战场）决定 eCPM 综合跑量表达。

🌿 一、商品力（货）— 影响 BID 出价能力

通过高纯度功能货盘、品牌力与精准人群定位，同步拉动 CTR/CVR 协同提升。

选品洞察：视频号全域选品趋势显示，中老年是热度最高的人群标签（1,452.2）、辅助降血脂是增速最快的功效词（↑586.55%）。骨骼健康品类选品热度 40.9，品牌竞争相对蓝海。

商品力金句：选品洞察决定货盘天花板，标杆案例验证闭环确定性。

⚡ 二、内容力（创意）— 影响 CTR 点击率

品牌力背书、痛点金句与 AIGC 创意素材。素材差异化是攻克同质化唯一性过滤的命门。

标杆：品牌E 创意重复度仅 10%（全场最低），素材生态最健康。商品点击率 48.2%。黄金前3秒痛点金句可一键复制。

跑量素材三步走：①摸清拿量核心要素 → ②把握跑量素材结构 → ③抓住素材流量密码
素材类型：病痛症状 / 症状口播 / 诊断画面 / 大字报 / 节目访谈专业人设

🏠 三、经营力（转化）— 影响 CVR 转化率

高转化率直播带货，直播闭环效率提升最大，直购近乎失效下的增量承接赛道。

标杆：品牌F 通便赛道 CVR 13-14% 全场最高，下单率 13.4%，客单价 ¥70-90。直播 vs 直购 ROI 差值 +0.90（全场最强）。

关键策略：
• 直播强机会：双链路胜出率 100%
• 增量承接：直购近乎失效时，直播闭环承接增量
• 蓝帽背书：建立信任，拉升下单转化与复购黏性

🚀 四、投放力（流量）— 表达层 eCPM 综合跑量

智投单链路 3002 + 多账户交叉 + 多版位拓展，让表达层 eCPM 足够稳，系统才敢持续放量。

标杆：品牌A 减肥规模化跑量：日耗 20-40w/d，CVR 8-9%，CTR 3-4%。

核心策略：
• 智投单链路 3002：无人驾驶冷启拓流
• 多账户交叉：摊薄单账户衰退，支撑稳定跑量
• 多版位拓展：CTR 强吸引力 + 多版位快速起量

🔷 阶段一：稳固基本盘 — CID 链路提效（当前→2周）

核心动作

  • ✅ 素材 CTR 攻坚：创意差异化策略，互选达人素材二次推广帮助提升素材双率
  • ✅ 多账户矩阵：增加投放主体及账户，提升创意唯一性ID，摊薄单账户衰退风险
  • ✅ 智投启动：智投同步开启，提升拿量能力

预期收益

  • 📈 CTR 从 1.0% → 1.5-2%
  • 📈 日耗从 30-35w → 35-40w
  • 📈 ROI 保持 1.3-1.5 区间
  • 📈 跑量稳定性提升

🔷 阶段二：开辟第二增长曲线 — 小店闭环链路（2-6周）

核心动作

  • ✅ 小店直购起盘：MoveFree大贸品优先走小店直购链路，利用微信小店送礼功能，撬动 CTR/CVR 双提升
  • ✅ 热招品牌申请：提升商品力和系统推荐权重
  • ✅ 全域通 CPA 模式：低成本测品测素材，无转化不扣费

预期收益

  • 📈 小店链路日耗 3-5w 冷启动
  • 📈 CVR 比 CID 提升 20-30%
  • 📈 送礼场景拉新人群差异化

🔷 阶段三：规模化增量 — 直播闭环链路（6-12周）

核心动作

  • ✅ 品牌自播直播间搭建：参照同品类标杆直播间搭建，以品牌力驱动高转化
  • ✅ 素材差异化：将品牌种草内容复用至直播投流，降低创意重复度
  • ✅ 直播间基建：参照闭环直播间基建指引 ↗
  • ✅ 多优化目标并行：下单/下单-ROI/24h下单多OG投放

预期收益（对标品牌E）

  • 📈 直播 ROI 比直购提升 +0.5 以上
  • 📈 峰值 GMV 膨胀 2-3x
  • 📈 CVR 从 2.3% → 5-8%
  • 📈 新增直播日耗 3-10w
